# 独立多帧深度回环验证：第一轮实验

严格方案没有恢复回环，五场景候选轨迹及点云均与同输入控制臂一致，没有新增精度收益。额外未验证边影子对照仅用于区分验证器与后端的影响，不能作为已验证方案。

## 固定实验条件

- 基于 develop@1f68d07；独立实验分支 exp/depth-loop-witness-20260907；原默认流程未修改。
- 保留当前几何假设、局部 ICP 边、DPV 里程计、优化权重规则、degree=4、25 cm/5° 绝对修正上限及原几何验收门。
- 只补验几何 accepted=true、原 PnP 终验失败的候选；没有重新计算被早期 PnP 拦截、尚无几何估计的其他候选。
- 验证帧位于 anchor ordinal 偏移 −32、−24、+24、+32，剔除原配准子图使用的帧和锚点。利用原短程 DPV 相对运动把冻结变换运输到验证帧，因此不完全独立于局部位姿质量。
- 两方向都须满足：至少 200 个支持点、投影覆盖≥15%、覆盖保留≥80%、可见比例≥35%、10 cm 内一致比例≥55%、可见深度残差中位数≤5 cm、截断深度损失相对 DPV 降低≥20%。至少 2 组有效验证，且至少 75% 的组两方向均通过。门限在运行前封存，未根据 GT 调参。
- 遮挡点不参与可见残差中位数，但仍计入截断损失和覆盖/一致比例，避免靠隐藏错误点通过。
- 可用时检查测量边三角环一致性；此次没有可评估的相关测量三角环，不能宣称多回环一致性已验证。

## scene0030_00 为什么仍被拒绝

唯一符合补验条件的是 361→2028。四组验证中两组通过，预设要求至少三组。前两组相对 DPV 的深度误差也有明显下降，但绝对残差超过 5 cm：

| 验证帧对 | 正向残差中位数 | 反向残差中位数 | 双向通过 |
|---|---:|---:|---|
| 324→1991 | 7.24 cm | 7.45 cm | False |
| 332→1999 | 5.34 cm | 5.90 cm | False |
| 390→2053 | 2.56 cm | 1.78 cm | True |
| 398→2066 | 3.08 cm | 2.04 cm | True |

这些结果说明“新验证器仍然拒绝”，不等于这条几何变换一定错误，也不等于直接把门限改到能通过就是可靠修复。固定绝对阈值、深度噪声与验证帧的 DPV 运输误差尚需独立标定。

58 passed、51 subtests passed。五场景双臂完整轨迹与全帧 TSDF；另外一个影子诊断全帧重融合。原 28,306 个 RGB/Depth 文件通过像素哈希核验。GT 评价在推理封存后执行，严格臂和影子臂推理产物均核验未改变。
用户 CD 直接调用原脚本：双向最近邻均值相加、5 cm 下采样、完整 GT 网格顶点、首个有效 GT 位姿对齐，无 ICP/尺度拟合。
