# 轻量 RGB-D 三思路对照（2026-09-07）

这轮最值得保留的是普通局部几何 ICP：相对上一轮控制臂，三个网格场景平均 F-score **37.2620% → 41.6401%（+4.3781 pp）**，Chamfer-L1 降低 **5.9132%**；四场景合并平移/旋转误差降低 **0.8783% / 1.0471%**。几何 ROI 在此基础上的平均 F-score 增量接近零；彩色多尺度和当前方向权重实现均减少平均 F-score 收益。三者组合没有超过普通 ICP。

收益不代表所有指标都改善：普通 ICP 在 `0046_01` 的旋转 RMSE 增加 0.1909%、Chamfer-RMSE 增加 1.8873%，`0000_00` 也未通过旧厚度安全门。全部实验仍未通过旧双改善门，实际 committed 结果均回退 DPV，默认最终精度没有改变。

本轮没有加载 ColorPCR 或 PointDSC，也没有重新运行 CLIP 或引入新的模型权重。只消费上一轮已验证回环，并在 CPU 上生成局部 RGB-D 约束。这里试验的是几何区域筛选、多尺度彩色 ICP、方向信息权重；**没有对应的预测实例/节点匹配输入，因此语义对象引导本身尚未验证**。

四个已用于开发的场景，六个实验臂，共 24 项推理。所有推理和候选点云封存后，才运行独立 GT 评价。不能将本轮当作未见场景泛化实验。

## 三个思路怎样分开验证

| 实验臂 | 变化 | 应比较的基线 |
|---|---|---|
| control | 上一轮 verified loops + smooth_local，不加局部边 | 验证原结果可复现 |
| local_base | 在 control 上加入普通单尺度几何 ICP 局部边 | 衡量新增局部约束整体效果 |
| roi | local_base 增加固定初始位姿下的双向几何重叠区域筛选 | local_base |
| color | local_base 改为多尺度彩色 ICP | local_base |
| information | 与 local_base 完全相同的边、变换和权重，只增加方向信息加权 | local_base |
| combined | ROI + 多尺度彩色 ICP + 方向信息加权 | local_base 与 control |

区域筛选是语义区域引导的几何代理，不能据其好坏推断场景图对象筛选一定好或坏。彩色臂同时包含颜色项和多尺度策略，尚未分别消融这两个子因素。

## 固定输入和实现

- 同样 11,882 个 admitted RGB-D 帧，全部 23,764 个图片文件通过原始像素 SHA 核验。原回环不重新选择，不改变其变换或有效权重。
- 每个 anchor 使用 admitted 帧序号偏移 −8、0、+8 的帧构造彩色小点云；另取 +4（末尾取 −4）帧进行额外几何检查。这些检查帧不进入相应 anchor 的拟合云，但来自同一序列，不能视为独立场景验收集。
- 像素步长 6、输入体素 2.5 cm、每个拟合小云最多 12,000 点。RGB 按既有已配准 RGB-D 契约对齐到深度分辨率，并保存像素文件哈希；这不替代相机外参标定。
- 只对相邻 anchor 生成新局部边。普通 ICP 为 5 cm / 30 次迭代；彩色 ICP 为 10/5/2.5 cm / 20/15/10 次迭代。ROI 在初始 DPV 相对位姿下，以双侧最近邻 15 cm 范围固定。
- 新局部边更新最多 10 cm / 5°；两方向的额外检查帧固定支持上，点到面 RMSE 均须至少降低 1%，覆盖保留至少 95%，支持点至少 200。异常返回显式失败，不补单位变换或 GT。
- 信息矩阵用 source/right tangent 的点到面 Jacobian，旋转与平移尺度先转为无量纲量，再按最大特征值归一化，特征值比例下限 0.05。只作用于新 local_rgbd 边；它是几何方向性代理，不是标定好的概率，也不包含彩色残差的信息量。
- DPV 里程计先验保留。degree 从 2 设为 4，仅为容纳每 anchor 至多两条相邻局部边；每臂逐项确认原回环全部保留。全轨迹仍使用原 smooth_local 和 25 cm / 5° 绝对限制、5 cm / 2° 相邻限制。
- 最终 TSDF 保持全帧、2 cm voxel、8 cm truncation、4.5 m depth truncation。额外检查帧也进入最终完整融合；它们的用途是局部边准入，不能再把它们的准入残差当成独立最终精度证据。

完整 Precision、Recall、相对位姿误差、Chamfer-RMSE、全 GT mesh 次要评价见外部 `analysis.json` / `metrics.csv`。主评价保持 5 cm 阈值、3 cm 下采样、同一共同观测参考区域，并逐项核对 reference surface / mask 哈希一致。

普通 ICP 的 F-score 在三个网格场景分别增加 8.4891、2.3367、2.3084 pp；`0030_02` 的平移/旋转误差降低 37.9770% / 38.0430%，是最明显的收益来源。ROI 在两个 `0046` 场景优于普通 ICP，但在 `0030_02` 较差，平均收益相互抵消。

当前信息加权按最大特征值归一，弱方向只会减弱，未保持与标量权重相同的总约束强度。因此结果说明这版保守权重没有带来额外收益，不能推广为“信息矩阵方法无效”。彩色项也未独立标定曝光与光度一致性；这些实现仍属于小规模机制试验。

同一主机最多四个进程并发、每进程四个 OpenMP 线程。阶段时间会受其他场景并发负载影响，不能当作严格单进程延迟；新增局部边也增加位姿图求解成本。没有在本轮同输入运行 ColorPCR/PointDSC，所以不报告相对它们的加速倍数。

局部匹配轻量不等于全流程更快：最长 `0000_00` 的普通 ICP 臂仍用了约 386 s，对照约 269 s；`0030_02` 对照的 0.37 s 是没有候选、复用 DPV 的 no-op，不能用来计算同等工作量的加速比。后续可单独研究稀疏位姿图求解和局部边预算，而不是直接扩大图规模。
